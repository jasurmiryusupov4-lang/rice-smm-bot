# RICE SMM + FixSIM Telegram Bot ⚡

Ushbu bot ijtimoiy tarmoqlar uchun **SMM xizmatlari** va **Virtual SIM (SMS qabul qilish)** xizmatlarini taqdim etuvchi avtomatlashtirilgan Telegram botdir.

## 🚀 1-Click Deploy to Render (Bepul 24/7 Hosting)

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/jasurmiryusupov4-lang/rice-smm-bot)

### Sozlamalar (Environment Variables):
- `BOT_TOKEN` - Telegram Bot Token (@BotFather dan)
- `ADMIN_ID` - Adminning Telegram ID raqami
- `FIXHAMYON_API_KEY` - FixHamyon to'lov tizimi API kaliti (ixtiyoriy)
- `SMM_API_URL` - SMM Provayder v2 API manzili (ixtiyoriy)
- `SMM_API_KEY` - SMM Provayder API kaliti (ixtiyoriy)
- `SMS_API_KEY` - SMS-Activate API kaliti (ixtiyoriy)
